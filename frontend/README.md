# OnboardAI — Frontend

React + Vite frontend for OnboardAI: RAG-Powered New Joiner Support Platform.

## Features

- Sign-in page (email and password; server-side session cookie, CSRF token kept in memory only)
- Employee dashboard showing the signed-in employee's own workspace
- AI Assistant with cited answers, employee-specific chat history, feedback and escalation to HR/IT
- Interactive onboarding checklist
- Leave balances and payroll calendar
- IT asset information
- Support ticket creation and history

## Local Development

### Prerequisites

- Node.js and npm
- Running OnboardAI FastAPI backend

### Start the Backend

From the project root:

python -m uvicorn backend.main:app --reload --port 8000

### Start the Frontend

From the frontend directory:

npm install
npm run dev

Open http://localhost:5173. The Vite dev server proxies `/api/*` to `http://127.0.0.1:8000` (see `vite.config.js`).

### Test and Build

npm test          # helper tests with the Node test runner
npm run build     # production build in dist/

### Docker

`Dockerfile` builds the app and serves it with nginx; `nginx.conf` proxies `/api/*` to the `backend` service, matching the dev proxy. Start the full stack from the project root with Docker Compose (see the root README).

## Important Notes

- All data is synthetic demo data.
- Identity comes from the backend session; the employee shown is always the signed-in account (the backend enforces own-data access).
- Backend API endpoints must be available for employee features.
- Azure production build: `deploy/azure/frontend.Dockerfile` (nginx template with the backend proxy key); `Dockerfile` and `nginx.conf` here are for local Docker Compose.
- Answers are generated by the backend with Azure OpenAI GPT-4.1; the frontend never calls the LLM directly.
